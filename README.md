# 半小时震动

本分支增加 **HUAWEI WATCH FIT 5 手机联动**，APK 安装在安卓手机，手表通过华为运动健康接收通知。[详细设置与限制](docs/HUAWEI-WATCH-FIT-5.md)。

## 手机和手表一起提醒

1. 在安卓手机安装本分支 APK，在首页打开「HUAWEI WATCH FIT 5 联动」。升级时默认保留原模式，需要手动打开联动开关。
2. 完成「权限与设置」向导：保持原手机强提醒权限，并允许「手表联动提醒」通知；配对华为运动健康，授予其通知使用权、后台运行权限，在设备的消息通知中开启「半小时震动」。
3. 手表关闭勿扰/睡眠模式；运动健康如有「多设备提醒」选项，请选中，避免手机亮屏时手表静默。
4. 点「测试手机和手表一起提醒」，等待至少 30 秒检查第二次手表提醒，最后在手机点「我现在去休息」。

到点后，手机仍持续震动和闪屏，同时立即发布一条普通通知，之后每 30 秒重新发送，让手表尝试重复振动。**手表每次振动由系统控制，可能被限频，不能保证马达持续不停。** 手机点「我现在去休息」后，手机强提醒及重复通知一起停止，按确认时间重新排下一次 30 分钟提醒。

手表无需安装应用，需与手机保持连接。程序无法检测手表送达或振动，停止后已经转发的消息可能仍留在手表；断连期间不保证补发。联动开关关闭时保留原手机模式，切换联动开关会结束当前提醒并重新计时。

安卓 APP，唯一功能：在设定的时段内每 30 分钟让手机**强力震动 + 全屏红白闪烁**，直到点“我现在去休息”才停；点完以后 30 分钟再震。

## 功能

- 总开关
- 每周哪几天（周一到周日任选）
- 每天几点到几点（开始晚于结束 = 跨午夜；开始等于结束 = 全天）
- 到点：震动 + 全屏闪烁 + 点亮屏幕（锁屏、熄屏、正在用别的 APP 时都会弹出）
- 只有点“我现在去休息”才停止；返回键、返回手势无效；按电源键熄屏几秒后会重新亮起
- 点完按钮后 30 分钟再震；超出时段则顺延到下一个时段开始后 30 分钟
- “立即测试一次震动”按钮，装好后先测一下

## 为什么它能震、别的 APP 不震

| 常见原因 | 本应用的做法 |
| --- | --- |
| 普通震动在静音/勿扰/熄屏时被系统掐掉 | 震动按“闹钟”类别（`USAGE_ALARM`）下发，系统对闹钟震动放行 |
| 震动强度低 | 振幅固定 255（安卓 API 允许的最大值），每次连续震 1.2 秒、停 0.3 秒循环；多马达手机同时驱动所有马达 |
| 后台被杀、定时不准 | `setAlarmClock` 系统闹钟级定时（不受 Doze 推迟）+ 前台服务 + 唤醒锁 + 忽略电池优化 |
| 震着震着停了 | 每 20 秒重新下发一次震动；开机/升级/改时间后自动重排；每次响铃时预先排好下一次作为兜底 |

## 设置向导

打开 APP 时，如果还有没完成的设置，会自动进入向导，**一次只处理一步**：

1. 先弹说明窗口：这一步为什么需要、你要点什么
2. 你点「去开启」后，才打开系统权限弹窗或设置页
3. 返回 APP 后自动检查结果：成功进入下一步；没成功提示再试一次，也可以跳过
4. 系统查不到状态的项目（小米省电策略、锁定后台、振动强度、勿扰），回来后由你点「我已完成」确认
5. 最后提示测试一次

首页「权限与设置」里每一项都可以单独点开重做。

小米/红米额外检测和引导：后台弹出界面与锁屏显示、自启动、省电策略无限制、最近任务锁定。

## 构建

```
./gradlew assembleRelease
```

APK 在 `app/build/outputs/apk/release/`。GitHub Actions 每次 push 也会自动构建并上传 APK。

签名用的是仓库里的 `app/halfhour.keystore`（固定签名，以后的新版本可以直接覆盖安装）。
